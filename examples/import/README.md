# 앱에 등록할 수 있는 태진·금영 CSV

## 최신 영상 연결 결과 (2026-11-04)

- **`tj-ky-songs-with-videos.csv`**: 전체 114,968곡, 영상 링크 40,473곡 포함. 최신 전체 등록용 파일입니다.
- **`linked-songs-only.csv`**: 영상이 연결된 40,473곡만 포함합니다.
- **`tj-ky-video-link-status.csv`**: 전체 곡의 현재 연결 상태와 미연결 사유입니다.

현재 실행 중인 DB에는 연결 결과를 이미 적용했습니다. 나머지 74,495곡은 아직 연결되지 않았습니다. 기본 반주를 우선하고, 사용자가 허용한 공식 MR 대체도 포함합니다. 실제 모바일 재생까지 확인한 목록은 아닙니다.

## 초기 곡 목록

이 폴더의 초기 파일은 앱의 **곡 관리 → CSV 가져오기**에서 바로 등록할 수 있습니다. 세 파일 중 통합 파일 하나 또는 브랜드별 파일을 선택하세요.

| 파일 | 곡 수 |
| --- | ---: |
| `tj-ky-songs-import.csv` | 114,968 |
| `tj-songs-import.csv` | 57,933 |
| `ky-songs-import.csv` | 57,035 |

헤더는 `brand,song_number,title,artist,youtube_url`입니다. UTF-8 BOM/CRLF 형식이며, 통합 파일도 20MB/120,000행 제한 안에 들어갑니다. 앱 CSV 파서와 실제 MySQL 업로드로 검증했습니다. 파일 생성만 수행하며 사용자 DB에 자동 등록하지 않습니다.

## 같은 번호 처리

- `TJ + 12345`와 `KY + 12345`는 서로 다른 곡으로 저장합니다.
- 같은 브랜드와 번호를 다시 등록하면 제목·가수를 갱신합니다.
- 표시 번호의 앞자리 0은 보존하되, 식별할 때 `TJ 00123`과 `TJ 123`은 같은 곡으로 처리합니다.
- 번호가 없는 기존 영상 등록 형식도 지원합니다. 이때는 브랜드와 영상 ID로 식별합니다. 나중에 번호를 붙여 새로 등록하면 별도 곡이 되므로 처음부터 번호를 지정하는 편이 좋습니다.
- 같은 브랜드·번호의 여러 영상은 마지막으로 지정한 영상 하나를 사용합니다.

## 영상 연결

영상 링크가 없는 곡은 **목록 검색·즐겨찾기**에 사용할 수 있습니다. 화면에 ‘영상 미연결’로 표시되며 예약은 비활성화됩니다. **영상 연결**을 누르면 브랜드·번호·제목이 입력된 관리자 창이 열립니다. 관리자 토큰과 확인한 YouTube 링크를 입력해 저장하면 예약할 수 있습니다.

기존 20곡 파일에서 브랜드·번호·가수가 일치하는 19곡의 영상 링크를 포함했습니다. 나머지는 빈칸입니다. 영상의 현재 재생 가능 여부는 별도 확인이 필요합니다. 링크 없는 CSV를 다시 가져와도 DB에 저장된 영상 링크는 지우지 않습니다.

## 출처

[catalog/README.md](../catalog/README.md)의 공개 API 스냅샷을 앱 형식으로 변환했습니다. 누락·폐곡 여부 및 제조사 실제 전곡과의 일치는 보장하지 않습니다. CSV 검증을 위해 제목·가수의 앞뒤 공백과 제어문자를 정리했습니다. 변환 내역·파일 크기·해시는 `manifest.json`에 있습니다.

재생성: 프로젝트 루트에서 `python3 scripts/prepare-import-csv.py`를 실행합니다. 다운로드는 다시 수행하지 않으며 기존 로컬 카탈로그를 변환합니다.
