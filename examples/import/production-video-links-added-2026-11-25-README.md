# 운영 DB 미연결 곡 추가 연결 CSV

- 파일: `production-video-links-added-2026-11-25.csv`
- 기준: DBeaver `mintech_aws` 폴더의 AWS MySQL 연결, `tj_karaoke.karaoke_songs`.
- 운영 DB 확인: 2026-11-25 10:04:47 및 10:07:31 한국 시간. 전체 114,968곡, 기존 연결 43,462곡, 미연결 71,506곡.
- 추가 연결 가능: **168곡 — TJ 58곡, KY 110곡**. 일반 반주 62곡, 공식 멜로디 제거(MR) 버전 106곡입니다.
- UTF-8 BOM / CRLF, 16,473바이트. 헤더는 `brand,song_number,title,artist,youtube_url`이며 앱의 실제 가져오기 파서로 168행을 검증했습니다.

## 적용

운영 사이트의 **곡 관리 → CSV 가져오기**에서 CSV를 선택하고 서버 관리자 토큰으로 등록합니다. 이번 작업에서는 운영 DB를 읽기 전용 트랜잭션으로 조회했으며, 영상 연결을 직접 변경하지 않았습니다.

같은 브랜드·번호 행의 제목·가수·영상 링크가 CSV 값으로 갱신됩니다. 생성 이후 운영에서 별도로 연결하거나 수정한 곡이 있다면 적용 전에 해당 행을 확인하세요. 168곡이 모두 적용되고 그동안 다른 변경이 없다면 연결곡은 43,630곡, 미연결은 71,338곡이 됩니다.

## 검증 범위

공식 TJ·KY 채널의 최근 업로드 각 1,000개와 운영 미연결 목록에서 선정한 곡별 검색 최대 80회를 조회했습니다. 고유 영상 2,041개를 현재 YouTube Data API 메타데이터로 확인했습니다. 공식 채널, 제목·가수 일치, 곡 번호의 충돌 여부, 공개 상태, 외부 재생 허용, 한국 지역 제한을 검사했으며 기존 연결곡은 제외했습니다. 영상에 번호가 없는 경우 기존 도구의 제목·가수 유일 일치 규칙을 적용했습니다.

전체 미연결 곡의 검색을 완료한 결과는 아닙니다. 실제 브라우저에서 재생하거나 음원을 청취한 검증은 수행하지 않았으며, YouTube 제공 상태는 이후 변경될 수 있습니다.

곡별 영상 제목·공식 채널·확인 시각·버전과 검사 결과는 [검증 보고서](../video-links/production-video-links-added-2026-11-25-report.json)에 있습니다. 접속 비밀번호와 API 키는 CSV·보고서에 포함하지 않았습니다.
