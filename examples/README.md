# 일괄 등록용 CSV

태진·금영의 대규모 곡 정보 목록은 [catalog/README.md](catalog/README.md)를 확인하세요. 앱에 바로 등록할 114,968곡 파일은 [import/README.md](import/README.md)에 있습니다. 영상 없는 곡은 검색 목록으로 등록하고 추후 영상을 연결할 수 있습니다.

`tj-songs-starter-20.csv`는 실제 곡 정보와 YouTube 링크를 담은 초기 등록용 20곡 목록입니다. Excel에서 한글을 읽을 수 있도록 UTF-8 BOM 및 CRLF 줄바꿈으로 저장했습니다.

## 가져오기

1. 앱의 **곡 관리**를 엽니다.
2. 로컬 `.env`의 `ADMIN_TOKEN`을 입력합니다.
3. **CSV 가져오기**에서 `tj-songs-starter-20.csv`를 선택하고 등록합니다.

앱에 같은 영상 ID가 있으면 기존 정보를 갱신합니다. 이 파일은 앱 CSV 파서로 검증했으며, 20행 모두 형식이 유효하고 중복 영상 ID는 없습니다. DB에는 자동 등록하지 않았습니다.

## 출처와 확인 범위

- 출처: [하북트진 — 노래방 인기곡(발라드, TJ)](https://heart2north.tistory.com/entry/노래방-인기곡발라드-TJ), 2023-06-24 게시.
- 위 공개 페이지에 함께 기재된 곡 제목·가수·TJ 번호·영상 링크 중 20곡을 옮겼습니다. 일부 띄어쓰기와 OST 표기를 정리했습니다.
- 확인 날짜: 2026-11-03. 최신 인기 순위나 TJ 전체 곡 목록이 아닙니다.
- YouTube 영상 페이지를 직접 불러올 수 없어 현재 공개 상태, 공식 채널 소속, 외부 재생 가능 여부는 개별 검증하지 못했습니다. 앱에서 재생 확인 후 사용하세요.
- 추가 곡은 같은 헤더(`title,artist,tj_number,youtube_url`) 아래에 입력하세요. 쉼표가 있는 제목은 CSV 편집기가 자동으로 큰따옴표 처리하도록 하세요.
