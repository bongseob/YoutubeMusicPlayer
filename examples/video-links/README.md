# 영상 연결 작업 기록

2026-11-03에 기존 곡 목록과 공개 영상 후보를 대조해 연결한 내역입니다. 사용자가 기존에 지정한 영상은 덮어쓰지 않습니다.

## 이번 추가 연결

- 입력: `candidates-batch-02.json` — 중복 키를 정리한 113곡 후보
- 확인 성공 및 DB 연결: **65곡**
- 기존 연결 유지: 21곡
- DB 곡 번호 없음: 8곡
- DB와 제목/가수 불일치: 4곡
- 메타데이터 조회 실패: 14곡
- 기본 반주와 다른 버전(멜로디 제거): 1곡
- 완료 후 DB 전체 연결 곡 수: **88곡** / 등록 114,968곡

`candidates-batch-02-matched.csv`는 확인된 65곡의 등록용 CSV입니다. 현재 DB에는 이미 반영했습니다. `candidates-batch-02-report.json`에는 변경 전 행, 조회 출처, 확인된 채널·영상 제목, 적용 여부를 저장했습니다.

`matched-3.csv`와 `applied-3.json`은 앞서 수동 대조해 연결한 3곡 기록입니다. 새 후보 목록에는 기존 곡을 포함할 수 있지만, 기존 연결을 유지하므로 추가 연결 수에 중복해서 세지 않습니다.

## 확인 범위

영상 후보는 다음 공개 곡 목록에서 확인했습니다.

- [TJ 발라드 목록](https://heart2north.tistory.com/entry/노래방-인기곡발라드-TJ)
- [TJ 트로트 목록](https://heart2north.tistory.com/entry/노래방-인기곡트로트-TJ)
- 개별 공개 검색 기록(각 후보의 `discovery_source` 참고)

후보의 브랜드·번호가 DB에 존재하고 제목·가수가 일치하는지 먼저 검사했습니다. 이후 [Noembed 공개 메타데이터 API](https://noembed.com/)로 영상 ID, 공식 채널 URL, 영상 제목과 가수를 대조했습니다. 일반 유튜버의 커버, 다른 가수, 키 변경·메들리·멜로디 제거 등은 자동 적용에서 제외합니다.

번호는 공개 목록과 DB를 대조한 값이며, Noembed는 곡 번호를 독립적으로 인증하지 않습니다. 영상의 실제 재생, 지역별 제한, 현재 브라우저의 외부 재생 가능 여부까지 검증한 것은 아닙니다. 영상이나 음원은 다운로드하지 않았습니다.

## 재실행

프로젝트 루트에서:

```sh
node scripts/link-reviewed-videos.js                 # 대조만 수행
node scripts/link-reviewed-videos.js --apply         # 일치한 미연결 곡에만 적용
```

다른 후보 JSON을 지정하려면 `node scripts/link-reviewed-videos.js examples/video-links/다른후보.json --apply` 형식을 사용합니다. 이 스크립트는 후보 URL을 새로 검색하거나 채널 전체 영상을 수집하지 않습니다. 명시한 후보를 확인하는 도구입니다. 보고서 파일은 같은 입력 경로의 `-report.json`에 저장되므로 과거 기록을 보존하려면 매 작업에 새 후보 파일명을 사용하세요.
