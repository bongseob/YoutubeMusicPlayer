## 권장 작업 순서

1. 기존 체크포인트로 공식 영상 검색 보완을 이어서 수행해 미수집 범위를 줄입니다. 새 API 조회와 적용은 이번 검토에서 수행하지 않았습니다.
2. 장르 주석, 공식 제목 접두어, 잘린 괄호 등의 표기 문제를 구분한 후보 목록을 만듭니다. 번호·브랜드·제목·가수 일치와 최신 임베드 상태를 다시 확인해야 합니다.
3. 임베드 불가 영상은 다른 공식 후보를 찾습니다. 제목 형식 검사와 임베드 검사를 함께 확인해야 실제 연결 가능 수를 산정할 수 있습니다.
4. COVER·키 변경·SEMI LIVE·번호 충돌은 검사 조건을 일괄 완화하지 않습니다.

기존 실행 도구와 상태 정의는 [전곡 영상 대조 안내](youtube-full-sync.md)를 참고하세요.
