한곡같이 사용 방법

한곡같이는 TJ·KY 곡을 검색하고 YouTube 반주 영상을 재생하는 모바일 노래방 웹 앱입니다. 친구들과 방에서 곡을 함께 예약할 수 있습니다.

혼자 노래 부르기

  1. 홈에서 노래 제목, 가수 또는 곡 번호로 검색합니다.
  2. 노래 옆의 ＋ 버튼으로 예약 목록에 추가합니다.
  3. 예약 목록의 ‘노래 시작하기’를 누릅니다.

친구들과 함께 부르기

  1. ‘방 관리’에서 내 이름을 입력하고, ‘새 방 만들기’를 누릅니다.
  2. ‘초대 링크 복사’로 링크를 친구에게 보냅니다.
  3. 친구는 초대 링크를 열고 이름을 입력한 뒤 ‘방 입장’을 누릅니다. 방 코드를 직접 입력해도 됩니다.
  4. 참가자가 곡을 예약하면 방장이 노래를 시작합니다. 소리는 방장 기기에서 재생됩니다.

노래가 끝날 때까지 방장 화면을 열어 두세요. ‘방 삭제’를 누르면 모두의 방이 종료됩니다.

다음 곡 투표

방의 예약 목록에서 ‘다음 곡 투표’를 누르세요. 한 사람당 한 곡에 투표할 수 있습니다. 다른 곡을 선택하면 표가 이동하고, 같은 곡을 다시 누르면 취소됩니다.

득표수는 참가자들에게 공유되며 투표가 예약 순서를 자동으로 바꾸지는 않습니다. 방장만 ‘다음 곡으로 지정’으로 예약 맨 앞의 곡을 바꿀 수 있습니다. 재생 중인 곡은 계속됩니다.

곡이 재생되거나 예약에서 삭제되면 해당 곡의 투표가 끝납니다. 방에서 나가면 자신의 표도 없어집니다.

방장 변경과 방 삭제

현재 방장은 ‘방 관리 → 새 방장’에서 접속 중인 참가자를 선택하고 ‘방장 넘기기’를 눌러 권한을 이전할 수 있습니다. 방장 기기의 응답이 60초 이상 없으면 참가자의 방 관리에 ‘방장 맡기’가 표시됩니다. 먼저 요청이 처리된 한 명이 새 방장이 됩니다.

예약과 투표는 유지되며 소리는 새 방장 기기에서 재생됩니다. 현재 곡은 처음부터 다시 시작될 수 있고 마이크는 새로 켜야 합니다. ‘방 삭제’는 방과 예약을 모두 삭제합니다. 자리를 떠나려면 다른 참가자에게 방장을 넘긴 뒤 ‘나가기’를 사용하세요.

자주 묻는 질문

‘영상 미연결’ 곡은 재생할 수 있나요?

아직 재생할 수 없습니다. 영상이 연결된 다른 곡을 선택해 주세요.

친구 휴대폰에서도 소리가 나오나요?

함께하는 방에서는 방장 기기에서 소리가 나옵니다. 참가자는 곡 예약에 참여합니다.

즐겨찾기는 친구와 공유되나요?

즐겨찾기는 현재 기기의 브라우저에 저장됩니다. 방의 예약 목록은 참가자들과 공유됩니다.

TJ미디어의 공식 서비스인가요?

TJ미디어와 무관한 개인용 앱입니다. YouTube 영상은 원본 제공 상태와 재생 제한에 따라 이용하지 못할 수 있습니다.
